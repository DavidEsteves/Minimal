# Changelog

## [1.0.0] — 2026-11-08

First public release of Minimal for Windows 10 and 11 (x64).

- Tabbed text editing, drag-and-drop opening, undo/redo, and customizable fonts and spacing.
- Syntax highlighting for 13 languages, a per-tab language picker, matching brackets, and code folding.
- Find and replace with regular expressions, whole-word matching, and navigable results.
- Automatic indentation and on-demand, token-preserving JSON/XML formatting.
- Offline Markdown preview with tables, task lists, highlighted code, and restricted local images.
- Session restoration and recovery of unsaved documents, with conflict-aware file saves.
- Encoding selection, BOM detection, and preservation of existing line endings.
- System, Light, and Dark themes, a compact native window, and offline third-party notices.

### Distribution

- Portable, framework-dependent Windows x64 ZIP; no installer or automatic updater.
- Requires the .NET 8 Desktop Runtime. Markdown preview additionally requires the Microsoft Edge WebView2 Runtime.
- Includes the MIT license and all bundled dependency license notices.
